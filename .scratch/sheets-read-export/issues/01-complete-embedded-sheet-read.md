# 01: 内嵌跨行列完整读取

**What to build:** 用户读取含电子表格的文档时，超过 100 行、跨多个列区间和稀疏区域的单元格都能出现在 Markdown 中。不存在的工作表不会被替换为第一张表，读取失败不会输出伪装成完整结果的部分表格。

**Blocked by:** None (can start immediately).

**Status:** completed (automated acceptance; live API unverified)

**阶段：** 一，内嵌读取。

**范围边界：** 接通 docs_ai 标签展开及 read 的 Block 回退，cat 的 docs_ai 路径自然复用；cat 的 Block 回退由 04 处理。响应过大自动拆分、业务限频恢复和 revision 变化检测分别由 02、03 增加；本任务遇到这些未恢复的错误须保留占位并告警。暂不增加独立读取或新 CLI 选项。

**交付约束：** 在本切片中先提取共享读取 Module 和纯 Markdown 渲染 Module，再改造已有调用者。调用者只传明确表格 token 与工作表 ID，不了解分块协议；元数据、验证、范围合并隐藏于读取 Interface。无需预建后续命令、缓存框架或通用后端 Adapter。

- [x] 使用工作表属性确认准确目标、类型与网格行列数量。缺少、非法或不存在的 sheetId 不回退其他表；不支持类型明确告警。
- [x] 使用有限完整坐标按 500 行 × 50 列规划初始分块并遍历全部目标区域；删除本地 101 行裁剪，不新增隐式数据上限。
- [x] 以至少 1,200 行、120 列的唯一坐标样例验收跨行列合并：后两批行及第 100 列以后的值仍在正确位置，无重复、漏行或错列。
- [x] 中间空块、返回短块、首行短于后续行均不导致提前结束或裁掉后续有效列；只移除整表尾部全空行列，保留前部与中间空白。
- [x] 对响应维度、范围与值结构进行校验；越出请求范围或自相矛盾的响应失败，不能作为空表成功处理。所有分块成功后才返回二维值结果。
- [x] 采用设计约定的文本、日期与用户 ID 读取选项；二维结果保留值和坐标，空白位置规范化；不按表头生成对象，不实现本地公式计算。
- [x] Markdown 保留现有首行表头规则，同时覆盖空/重复表头、0、false、空值、日期、管道符、反斜线、换行和复合单元格；未知复合值保留可读信息，不出现意外的对象默认字符串。
- [x] 真实空表输出空表说明；任意请求失败保留该表原标签或占位并给出 recovery，正文其余内容照常输出，已读取的部分表格不会替换标签。
- [x] 同一文档重复引用只读取一次，替换顺序保持原样；工作表任务最多 5 个并发，单表分块顺序请求。
- [x] 从现有 read 的 docs_ai 与 Block 回退入口均可演示新行为；无 Sheet 的文档、raw/blocks 模式及其他内嵌类型保持原行为。
- [x] 针对公开读取/渲染 Interface 及必要命令回归新增测试，npm test 通过；记录稀疏坐标真实样例是否已验证，未验证时不宣称接口行为已实测。

**独立验收演示：** 对同一份带大表、重复引用和失败引用的文档，分别模拟 docs_ai 成功与 Block 回退。核对超过 100 行和 100 列的数据、空白位置及失败占位；两种 read 路径结果一致。
