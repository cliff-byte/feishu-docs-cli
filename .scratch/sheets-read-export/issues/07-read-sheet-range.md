# 07: 指定矩形范围读取

**What to build:** 用户能为唯一工作表指定有限矩形范围，只获取并输出该范围内的数据；中间或边缘空白不移动坐标，Markdown 不把选中区域的第一条业务记录误认成表头。

**Blocked by:** 05 — 独立单工作表 Markdown/JSON 读取。

**Status:** completed (automated acceptance; live API unverified)

**阶段：** 二，独立读取。

**范围边界：** 增加 --range 有限 A1 矩形选择及对应渲染模式。不支持开放范围、多个范围、工作表名称表达式、过滤器或导出裁剪；不依赖 06 的整本输出算法。

- [x] --range 接受不含工作表前缀的有限矩形，如 A1:F2000；能够规范化大小写，但拒绝非法、倒序、零/负行、超出网格或过大不可安全表示的坐标，不静默裁剪。
- [x] 目标选择沿用 --sheet 优先于 URL sheet；未选择时仅在能唯一确定普通工作表的情况下允许范围读取，多工作表歧义明确报 INVALID_ARGS。
- [x] 校验完成后只规划所选矩形内的值请求，不先读取整表再裁剪；超过分块尺寸的范围仍复用超限恢复、坐标合并及版本检查。
- [x] 范围起点不在 A1 时，输出仍准确对应原始列与行；缺失位置以 null 补齐，前部、中间和尾部空白全部保留。
- [x] 显式范围即使全空也保留请求尺寸的二维空值矩阵，requested_range 与 data_range 均为规范化请求范围；与整表空结果规则明确区分。
- [x] Markdown 以原工作表列字母作为表头，选中范围的第一行和最后一行都作为数据输出，不消耗首条业务记录作表头。
- [x] JSON 保留二维值及坐标；--with-meta 能说明实际选择范围。不存在的工作表和末块失败沿用整体失败语义。
- [x] 测试覆盖非 A1 起点、超过 Z 的列名、跨块范围、单格矩形、全空范围、边缘空白、越界/非法/歧义输入，以及整表读取回归；npm test 通过。
- [x] 同步范围语法、表头区别及唯一工作表要求的使用说明。

**独立验收演示：** 读取从 C200 开始、跨多个分块且末行为空的范围，核对列字母表头、第一条业务记录、最后空行和 JSON 矩阵尺寸；请求次数和坐标证明没有扫描所选范围之外的数据。
