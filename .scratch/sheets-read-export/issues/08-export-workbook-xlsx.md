# 08: 整本 xlsx 安全导出

**What to build:** 用户提供电子表格来源和本地输出位置，CLI 完成官方导出任务、有限等待、流式下载及安全落盘，得到可使用的整本 xlsx；失败明确退出，绝不覆盖已有文件或把错误响应当文件保存。

**Blocked by:** 06 — 整本多工作表读取；07 — 指定矩形范围读取。此门槛落实用户要求的阶段顺序，不表示导出依赖读取全部单元格。

**Status:** completed (automated acceptance; live API unverified)

**阶段：** 三，导出。

**范围边界：** 首次交付即包含完整导出路径及必要的身份、超时和文件保护。暂态失败自动恢复与步骤级授权恢复由 09 增加；未恢复的失败在本任务中须安全结束。只导出整本 xlsx，不支持 CSV、单表 xlsx、范围裁剪或覆盖开关。

- [x] export 接受 sheets/wiki URL 和 --type sheet 的裸 token；知识库解析为真实表格 token，非表格输入明确拒绝，不读取或解析全表单元格来生成文件。
- [x] --format 默认且仅支持 xlsx；--output 必填，目标目录必须存在。拒绝 --sheet/--range，URL sheet 参数不裁剪文件且输出明确说明导出整本。
- [x] 通过现有鉴权层创建导出任务、使用 ticket 与原表格 token 查询、成功后下载产物；0 表示成功、1/2 表示等待，其他状态及畸形结果明确失败。
- [x] 创建 POST 禁用不确定结果的自动重试；已创建任务后发生任何失败都不再次创建。创建、查询、下载保持同一用户或应用身份，不从 user 切换到 tenant。
- [x] 轮询采用约 2 秒间隔和默认 120 秒截止时间，在途查询也受剩余等待预算约束；超时报告 ticket 和 recovery，不声称取消远端任务。
- [x] 导出权限按 API 错误返回提示恢复，不扩充默认 scopes、不建立命令到 scope 的本地映射。任务状态失败与权限/不存在错误使用适当 CliError，日志不含凭证。
- [x] 下载采用鉴权流式落盘并尊重背压；传输超时覆盖完整响应体，识别 JSON 错误、非成功响应及文件大小不符，不缓冲整份文件、不重写 xlsx。
- [x] 只使用用户指定的目标路径；远端文件名不决定本地目录。目标目录内独占创建仅当前用户可访问的临时文件，等待写入与关闭后才发布。
- [x] 已有目标在开始前及最终发布时均受保护；并发出现同名文件也不得覆盖，发布采用不覆盖目标的原子操作，不支持时明确失败。
- [x] 请求失败、下载中断或校验失败清理本次临时内容，不删除用户文件；普通中断尝试清理，强制终止遗留临时文件的限制明确记录。
- [x] 文件成功发布后才输出成功及 path/format/size；JSON 使用现有 success envelope，进度写 stderr。失败不输出成功路径，已有目标内容保持不变。
- [x] 从 export 命令入口覆盖完整流程、等待/任务失败、未知状态、固定身份、创建超时不重复、传输失败、大小校验、已有目标与并发目标保护；使用计时器和流式样例验收，npm test 通过。
- [x] 更新实际命令帮助；记录真实 xlsx 是否已下载并由本地工具打开核验，不把 mock 字节保存成功当作兼容性已验证。

**独立验收演示：** 模拟任务由初始化到成功，分段返回文件字节，确认导出命令产出完全一致的文件并报告正确大小；再验证目标已存在、下载停滞及任务超时场景，均无覆盖或假成功。
