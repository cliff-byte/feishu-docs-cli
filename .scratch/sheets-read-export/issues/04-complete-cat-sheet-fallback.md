# 04: 补齐 cat 回退读取

**What to build:** 用户通过 cat 读取知识库时，即使 docs_ai 不可用，Block 回退仍能输出完整内嵌电子表格，并继续遵守既有文档数量与输出字节限制。

**Blocked by:** 01 — 内嵌跨行列完整读取。

**Status:** completed (automated acceptance; live API unverified)

**阶段：** 一，内嵌读取。

**范围边界：** 仅补齐 cat 的 Block 回退中的 Sheet 内容。沿用共享读取和渲染 Module；不复制大表逻辑，不同时启用图片、画板、多维表格等其他补全，不改变独立非 docx 节点的现有占位行为。

- [x] docs_ai 失败后，cat 能识别文档中的 SHEET Block 并输出超过 100 行、跨列范围的数据，与 read 的对应结果一致。
- [x] 相同工作表在一篇回退文档中重复引用时仅读取一次，渲染顺序与 Block 顺序保持一致。
- [x] 表格读取失败保留其占位并给出恢复建议，其余正文和可处理节点继续输出，不把此类失败提升为整个遍历崩溃。
- [x] 真实空表输出空表说明，非 Sheet 内容保持既有回退表现。
- [x] 表格展开后的实际 UTF-8 字节数参与既有 max-bytes 判断；超过预算时按既有整篇跳过/停止规则处理，不先写部分正文或部分表格。
- [x] title-only、文档数量、深度及现有非 docx 节点行为不回归；docs_ai 成功时不额外触发 Block 获取。
- [x] 从 cat 命令入口覆盖成功回退、重复引用、表格失败和中文大输出超预算用例，不复制全部读取算法测试；npm test 通过。
- [x] 更新 cat 的实际能力说明，区分“内嵌表已完整读取”与“文档因输出预算被跳过”。

**独立验收演示：** 遍历一个含大表文档的知识库样例，模拟 docs_ai 不可用；预算足够时看到完整表格，预算不足时没有半张表输出且出现现有预算提示。
